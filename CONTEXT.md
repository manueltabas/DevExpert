# Glossary

These terms describe the agreed scoring workflow.

- **Game**: one play session with its own participants, score changes, and standings; not a board-game catalog entry.
- **Player**: a named participant in a game, identified visually by a color and marker. Players do not have accounts.
- **Scorekeeper**: the person operating the app for everyone on one device.
- **Score change**: a signed whole-number amount added to one player's total.
- **Total**: the sum of a player's score changes, starting at zero.
- **Leaderboard**: players ordered by descending total, with shared ranks for ties.
- **Finished game**: a saved, read-only game with final standings.
- **Play again**: create a separate game with the same players and zero scores.

“Round” describes the real board game but is not a required app step: players can receive points independently.
