# Glossary

These terms describe the agreed scoring workflow.

- **Game**: one play session with its own participants, score changes, and standings; not a board-game catalog entry.
- **Player**: a named participant in a game, identified visually by a color and marker. Players do not have accounts.
- **Scorekeeper**: the person operating the app for everyone on one device.
- **Score change**: a signed whole-number amount added to one player's total.
- **Total**: the sum of a player's score changes, starting at zero.
- **Leaderboard**: players ordered by descending total, with shared ranks for ties.
- **Finished game**: a saved, read-only game with final standings.
- **Play again**: create a separate game with the same players and zero scores.
- **Game title**: optional editable label for a game. Shown on cards and headers; when blank, an auto date-based label is displayed instead.
- **Player number**: the player's position in setup order (1–20), shown as a badge. A display aid for repeated colors or names; not part of player identity.
- **Recent entries**: the active game's logged score changes, shown newest first with relative timestamps.
- **Score distribution**: a stacked bar showing each player's share of the game's accumulated points.

“Round” describes the real board game but is not a required app step: players can receive points independently. Round/turn labels and timers seen in design mockups are decoration, not app behavior.
